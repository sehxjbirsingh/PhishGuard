PhishGuard REST API Explorer

Programmatic interface for integrating PhishGuard heuristic screening into mail transfer agents (MTAs) and SIEM pipelines.

Open Raw JSON Feed
POST /api/analyze

Perform a live heuristic threat evaluation on raw email text, sender domain, and URLs without saving to the database.

Request Body (JSON) 
{
  "sender": "security@paypaI-notice.example",
  "subject": "Action required: Account suspended immediately",
  "body": "Verify your identity immediately at http://paypal-verify.example/login to avoid suspension."
}
Response (200 OK) 
{
  "verdict": "phishing",
  "score": 0.99,
  "status": "quarantined",
  "reason": "Insecure HTTP or shortened link detected; Brand or account credential wording in URL; Urgent or threatening language; Sender identity/domain mismatch",
  "reasons": [
    "Insecure HTTP or shortened link detected",
    "Brand or account credential wording in URL",
    "Urgent or threatening language (action required, immediately, suspended)",
    "Sender identity/domain mismatch or spoofing indicator"
  ]
}
GET /api/messages

Retrieve the latest scanned messages, threat scores, heuristic verdicts, and reviewer disposition records.

Sample Curl Request 
curl -X GET http://127.0.0.1:5000/api/messages
Response (200 OK) 
[
  {
    "id": 1,
    "sender": "billing@paypaI-security.example",
    "subject": "Action required: account suspended",
    "score": 0.99,
    "verdict": "phishing",
    "status": "quarantined",
    "reason": "Insecure HTTP or shortened link detected; Urgent or threatening language",
    "received_at": "2026-11-17 14:15:00",
    "reviewed_verdict": null
  }
]
GET /api/messages/<message_id>

Retrieve complete details for a single message record, including the full body and reviewer override information.

Sample Curl Request 
curl -X GET http://127.0.0.1:5000/api/messages/1
